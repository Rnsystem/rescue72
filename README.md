# rescue72

災害発生後の“最初の72時間”に特化した人命救助支援プラットフォーム

---

## 🧭 概要

rescue72 は、大規模災害発生直後の「最初の72時間」における人命救助活動を支援するためのWebアプリケーションです。

災害発生後72時間は生存率が大きく左右される極めて重要な時間帯です。本プロジェクトは、通知機能・位置情報連携・情報共有基盤を通じて、迅速かつ効率的な初動対応を実現することを目的としています。

---

## 🎯 ビジョン

個ではなく「群」で支える災害対応へ。

rescue72 は単なるWebアプリではなく、将来的に分散型ノード間連携を実現し、地域単位で展開されたサーバー同士がセキュアに連携できる災害対応ネットワークの構築を目指します。

---

## 🚀 主な機能（計画）

- 災害発生時の一斉通知機能
- 事前登録エリアへのプッシュ通知配信
- ユーザー位置情報の取得・保存
- 被災状況の可視化
- APIによる外部連携
- 将来的な分散ノード間同期機能

---

## 🏗 システム構成（初期想定）

- Backend: Python / Django
- Database: PostgreSQL（予定）
- Frontend: Web / PWA対応予定
- Hosting: 未定（将来的にクラウド分散構成想定）

---

## 🔐 セキュリティ方針

- 位置情報取得はユーザーの明示的許可に基づく
- 通信はHTTPS前提
- 将来的にノード間通信の暗号化を実装予定

## 🌍 プロジェクトの思想

rescue72 は、災害時の混乱を最小化し、
「救える命を最大限救う」ための技術基盤を目指します。

72時間という限られた時間にフォーカスし、
迅速・分散・協調をキーワードに進化していきます。
